# Long Prior and Posterior Draw Table

Long Prior and Posterior Draw Table

## Usage

``` r
prior_posterior_draws_long(x, max_draws = 1000L, seed = 1L)
```

## Arguments

- x:

  A `gp3bayes_prior_posterior_bridge`.

- max_draws:

  Maximum draws per distribution and variable.

- seed:

  Non-negative integer seed.

## Value

A long draw table.
