# Audit empirical support for an advanced pupil model specification

This audit is deliberately heuristic. It identifies weakly supported
design configurations before sampling but does not certify model
identifiability or posterior adequacy.

## Usage

``` r
audit_advanced_pupil_identifiability(specification)
```

## Arguments

- specification:

  An advanced pupil specification.

## Value

A `gp3bayes_pupil_identifiability_audit` object.
