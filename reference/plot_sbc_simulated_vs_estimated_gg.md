# SBC Simulated-versus-Estimated Plot

SBC Simulated-versus-Estimated Plot

## Usage

``` r
plot_sbc_simulated_vs_estimated_gg(x, variables = NULL, ...)
```

## Arguments

- x:

  A `gp3bayes_sbc_result`.

- variables:

  Optional variables.

- ...:

  Arguments passed to SBC.

## Value

A plot object returned by SBC.
