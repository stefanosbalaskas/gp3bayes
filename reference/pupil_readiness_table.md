# Extract pupil readiness tables

Extract pupil readiness tables

## Usage

``` r
pupil_readiness_table(
  x,
  component = c("summary", "participant", "condition", "trial")
)
```

## Arguments

- x:

  A `gp3bayes_pupil_readiness`.

- component:

  One of `"summary"`, `"participant"`, `"condition"`, or `"trial"`.

## Value

A data frame.
