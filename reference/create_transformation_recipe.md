# Create a Reusable Transformation Recipe

Extracts the recorded condition coding, outcome mapping or unit
conversion, numeric scaling registry, fixed-effects formula, and
model-matrix columns from a prepared gp3bayes object.

## Usage

``` r
create_transformation_recipe(prepared)
```

## Arguments

- prepared:

  A binary or duration prepared object.

## Value

A `gp3bayes_transformation_recipe`.
