# Plot observed pupil trajectories

Plot observed pupil trajectories

## Usage

``` r
plot_pupil_observed_trajectory(x, summary = TRUE)
```

## Arguments

- x:

  Prepared pupil object.

- summary:

  Whether to plot condition means rather than individual
  participant-trial traces.

## Value

A `ggplot` object.
