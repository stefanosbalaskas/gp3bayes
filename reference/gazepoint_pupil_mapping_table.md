# Return the Gazepoint pupil mapping audit table

Return the Gazepoint pupil mapping audit table

## Usage

``` r
gazepoint_pupil_mapping_table(x)
```

## Arguments

- x:

  A result from
  [`inspect_gazepoint_pupil_schema()`](https://stefanosbalaskas.github.io/gp3bayes/reference/inspect_gazepoint_pupil_schema.md)
  or a compatible data frame to inspect.

## Value

A data frame with documented fields, roles, units, eye, and presence.
