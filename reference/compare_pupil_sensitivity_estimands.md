# Compare declared pupil sensitivity estimands

Combines already-computed pupil estimands by named scenario. No scenario
is ranked or selected.

## Usage

``` r
compare_pupil_sensitivity_estimands(results)
```

## Arguments

- results:

  Named list of `gp3bayes_pupil_estimand` objects.

## Value

A `gp3bayes_pupil_sensitivity_comparison`.
