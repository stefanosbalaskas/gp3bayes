# Estimand Interval Plot

Estimand Interval Plot

## Usage

``` r
plot_estimand_intervals(x, quantities = NULL, probs = c(0.025, 0.5, 0.975))
```

## Arguments

- x:

  A `gp3bayes_estimand`.

- quantities:

  Optional estimand quantities.

- probs:

  Posterior interval probabilities.

## Value

A `ggplot` object.
