# Register a Publication Table

Register a Publication Table

## Usage

``` r
register_publication_table(
  registry,
  name,
  table,
  caption = NULL,
  source = NULL
)
```

## Arguments

- registry:

  A publication registry.

- name:

  Unique entry name.

- table:

  A data frame.

- caption:

  Optional caption.

- source:

  Optional source label.

## Value

An updated registry.
