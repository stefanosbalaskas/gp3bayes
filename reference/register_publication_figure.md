# Register a Publication Figure

Register a Publication Figure

## Usage

``` r
register_publication_figure(
  registry,
  name,
  figure,
  caption = NULL,
  source = NULL
)
```

## Arguments

- registry:

  A publication registry.

- name:

  Unique entry name.

- figure:

  A ggplot, bayesplot grid, or gtable.

- caption:

  Optional caption.

- source:

  Optional source label.

## Value

An updated registry.
