# Summarise Workflow Stage Completion

Creates an inspectable stage map for a gp3bayes object. Stage completion
is descriptive only and is not an adequacy or validity declaration.

## Usage

``` r
model_workflow_status(x)
```

## Arguments

- x:

  A gp3bayes contract, prepared object, specification, fit, or evidence
  object.

## Value

A `gp3bayes_workflow_status` data frame.
