# Plot Governed Exact K-Fold Results

Delegates plotting to the LOO-compatible object returned by
[`brms::kfold()`](https://mc-stan.org/loo/reference/kfold-generic.html).

## Usage

``` r
# S3 method for class 'gp3bayes_kfold_cv'
plot(x, ...)
```

## Arguments

- x:

  A `gp3bayes_kfold_cv` object.

- ...:

  Arguments passed to the underlying plot method.

## Value

`x`, invisibly.
