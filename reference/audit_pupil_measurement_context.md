# Audit pupil measurement and confound context

Summarises declared blink/interpolation, baseline, PFE/gaze, luminance,
contrast, and sampling context without correcting or excluding
observations.

## Usage

``` r
audit_pupil_measurement_context(x)
```

## Arguments

- x:

  A prepared pupil object.

## Value

A `gp3bayes_pupil_measurement_audit`.
