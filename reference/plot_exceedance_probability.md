# Prediction Exceedance-Probability Plot

Prediction Exceedance-Probability Plot

## Usage

``` r
plot_exceedance_probability(x)
```

## Arguments

- x:

  A table returned by
  [`prediction_exceedance_probability()`](https://stefanosbalaskas.github.io/gp3bayes/reference/prediction_exceedance_probability.md).

## Value

A `ggplot` object.
