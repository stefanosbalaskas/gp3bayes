# Plot Group-Effect Posterior Distributions

Plot Group-Effect Posterior Distributions

## Usage

``` r
plot_group_effect_distribution(x, max_levels = 20L)
```

## Arguments

- x:

  A table returned by
  [`group_effect_draws_table()`](https://stefanosbalaskas.github.io/gp3bayes/reference/group_effect_draws_table.md).

- max_levels:

  Maximum displayed grouping levels.

## Value

A faceted `ggplot`.
