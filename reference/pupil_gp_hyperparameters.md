# Extract Gaussian-process hyperparameters

Extract Gaussian-process hyperparameters

## Usage

``` r
pupil_gp_hyperparameters(fit, probability = 0.95)
```

## Arguments

- fit:

  A fitted GP pupil model.

- probability:

  Central interval probability.

## Value

A `gp3bayes_pupil_gp_hyperparameters` object.
