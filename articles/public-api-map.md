# Complete Public API Map

This article is a discoverability index for the frozen development API.
It groups every exported function by its primary interface role.
Function names are linked by pkgdown to their full reference
documentation. The map is not a recommendation to call every low-level
adapter directly.

**Frozen development API size:** 324 exported functions.
